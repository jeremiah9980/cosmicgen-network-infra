CosmicGen Proof of Concept (PoC)

On-prem micro-cloud infrastructure with secure remote access

Overview

The CosmicGen PoC is a secure, segmented, on-prem infrastructure environment designed to validate compute, networking, and remote access capabilities using enterprise-grade tooling.

Network Architecture

  • WAN: 47.163.25.30
  • Gateway: Eero (192.168.0.1)
  • Core Switch: MikroTik CRS (192.168.0.254)
  • Subnet: 192.168.0.0/16

Compute Hosts

Host IPMI Proxmox
Host 1 192.168.5.200 192.168.5.210
Host 2 192.168.5.201 192.168.5.211
Host 3 192.168.5.202 192.168.5.212

Remote Access & Security

  • L2TP/IPsec VPN hosted on MikroTik
  • Per-user VPN credentials
  • IPsec NAT-Traversal enabled
  • Firewall rules restrict management access to VPN

Management Interfaces

  • Proxmox Web UI (Port 8006)
  • IPMI Web Consoles
  • MikroTik WinBox / SSH

Monitoring & Operations

The environment is designed to integrate with lightweight monitoring tools (Uptime Kuma, Prometheus, SNMP) to provide availability alerts and system health visibility.

Future Roadmap

  • Terraform-driven provisioning
  • Ansible configuration management
  • GPU compute expansion
  • Multi-site PoC replication
