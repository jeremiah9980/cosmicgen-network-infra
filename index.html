Overview

This page provides an overview of the CosmicGen proof‑of‑concept (POC) environment. The POC demonstrates a small scale network with a public WAN connection, secure VPN access, a MikroTik CRS326 switch/router, and three hosts running Proxmox VE alongside their IPMI management interfaces. The configuration, scripts and documentation for this environment are contained in the accompanying repository.

The diagram below illustrates the logical topology of the POC environment alongside a photo of the physical rack. Internet traffic flows through the Eero gateway and MikroTik CRS326 switch to Wi‑Fi/LAN clients, VPN clients, and the Proxmox/IPMI hosts.

📂 Repository Structure

The GitHub repository for this project is organised as follows. Click the links below to explore the corresponding resources.

  • README.md – high‑level description of the POC architecture and usage.
  • config/
    • CosmicGen-POC-SW1.cfg – MikroTik CRS326 configuration for the POC switch.
  • scripts/
    • Install-CosmicGen-VPN.ps1 – Windows PowerShell script to install VPN profiles for users.
  • docs/
    • BUILD_DOC.md – formal build document outlining all deployment steps.
    • runbook.md – runbook describing day‑to‑day operational tasks, troubleshooting and support.
